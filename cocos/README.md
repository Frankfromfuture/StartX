# StartX · Cocos 卡牌棋盘

工程使用 Cocos Creator 3.8.8。打开本目录，进入 `assets/scenes/CardSample.scene`。卡牌数据源是 `data/startx_data.xlsx`；Excel、原始插画、字体和构建工具均保存在本工程内。

棋盘、卡牌和供应链统一朝玩家倾斜 15°，采用近大远小的透视。点击、拖放、平移与缩放使用同一平面的坐标换算；横竖屏切换保留棋盘中心和缩放，顶部栏、卡包与菜单保持原有布局。

卡包整体偏平，中间略鼓，上下封口保留适量厚度，侧面保留包装折痕；棋盘、顶部卡包栏和长按预览使用相同轮廓。

卡牌、棋盘卡包、创始人气泡和现有界面阴影共用视角光源，在各自平面上投影，位置、缩放、抬起和转动变化时同步更新。卡牌阴影轮廓随牌面转动；顶部一排卡包保持原有表现。

奖励礼包与其他卡包使用相同的黑色纹理和侧面材质；3 颗很小的米白色星星交错闪现，熄灭后在包内随机换位，避开底部名称。未激活时保留灰色半透明状态。

界面文字、图标和卡包以 390 像素竖屏为尺寸基准，切换横竖屏或调整窗口时保持显示大小。卡包固定为 64 像素，详情页卡牌为 128 像素，详情文字和来源图标按原基准缩小 20%；空间不足时使用原有滚动区域。

标签展开、菜单和图鉴使用详情页同款半透明黑色背景（RGBA 16、19、25、190），面板内容保持清晰；不再使用模糊、百叶窗条纹或磨砂颗粒。

齿轮菜单和设置子页的字号、按钮及间距统一缩小 20%。设置子页新增横屏／竖屏模式切换，点击当前模式可切换，选择保存在本机；网页画布旋转时同步转换点击和拖放坐标，并保留棋盘缩放与中心位置。

横竖屏顶部图标的点击提示与创始人气泡，均比顶部栏文字小一档（约 12 像素），框体与留白随文字收紧；点击提示标题保持加粗。横竖屏底部三个图标与提示栏的内容框间距均约 2 像素。

从开始页开始或继续游戏、重新开局时默认运行；游戏内仍可主动暂停。继续／暂停图案再缩小 10%，显示尺寸为 38.88 像素，点击热区保留 64 像素。

创始人使用随台词长度调整大小的立体蜡笔气泡，以约 12 像素的显示字号和紧凑留白，在牌面上方由小变大出现并轻微上浮；黑色蜡笔边框略细于卡牌，阴影为短而半透明的深灰涂抹，外缘平稳，内部保留蜡笔笔触和纸纹。点击气泡外取消当前及待播台词。进入游戏时邀请冒险，新达成发展里程碑时祝贺；菜单和抽屉打开时暂时隐藏。已有存档中的历史里程碑不会重复触发祝贺。“发展里程碑”沿用原任务系统，标签比“商业模式”稍长；内容窗口上下延伸，右侧圆角与标签共用比例，仅活跃标签接合处开口，其余细实线边框完整闭合。

横屏下底栏与顶部栏等高，属性和带「」的 flavor 同排显示，上方卡包图标及底部三个图标的内容框与栏边间距约 2 像素。卡包默认隐藏，通过上方居中的手绘卡包图标展开，点击后图标隐藏、卡包原位出现，点击外部收起并恢复图标；卡包仍可横向滚动，奖励礼包位置固定。左侧标签使用“商业／模式”和“发展／里程碑”两行标签，约 40×84 像素，文字左对齐，重叠约 24 像素。竖屏保持原有排布；详情页 flavor 同样加「」。

横屏图鉴标题约 18.7 像素，计数及排序文字约 13 像素，排序按钮约 101×29 像素，卡面大小保留。横屏开始页 StartX Logo 按 2 倍目标放大并保留窗口边距，副标题缩为 18 像素；横竖屏创始人气泡均随顶部下一档字号缩小，在牌上方或靠近牌的侧边显示。横屏卡牌详情使用左卡右文两列。齿轮菜单移除“商业模式”，设置子页在横竖屏下都移除“全屏”。

## 构建与数据修改

首次安装依赖后，直接构建即可自动同步 Excel 和卡面：

```sh
npm install
npm run build:web
npm run preview
```

访问 http://127.0.0.1:4173/ 。微信小游戏使用 `npm run build:wechat`，正式 AppID 可通过 `WECHAT_APPID` 环境变量传入。Creator 安装位置不同时，将 `COCOS_CREATOR` 设为编辑器可执行文件路径。

`build:web` 和 `build:wechat` 都先读取 Excel 的 `cards`、`recipes`、`packs`、`tasks`，校验引用后生成 `assets/content/catalog.json`、全部卡面、卡包封面、数字贴片和配方图标。字体使用随工程提供的完整得意黑，新增中文名称也能显示。未修改的数据会复用已有产物。指定 `--scripts-only` 时，如果同步产生了资源修改，会自动改为完整构建。

Creator 项目扩展 `extensions/startx-data` 将同一同步入口接入编辑器构建。重新打开工程后，普通构建会先同步并刷新资源。扩展配置见 [Cocos 构建扩展文档](https://docs.cocos.com/creator/3.8/manual/en/editor/publish/custom-build-plugin.html)。命令行构建独立执行同步，即使未打开编辑器也能使用。

数据位置与字段用法见 [数据说明](data/README.md)。只想更新编辑器预览中的卡面时，可运行 `npm run sync:data`。新增卡牌插画放到 `data/art/cards/<id>.png`，新增卡包插画放到 `data/art/packs/<id>.png`，也支持 SVG。商业模式卡随配方自动生成。

Excel 中的卡牌数值、名称、说明、配方和卡包配置由构建同步。特殊能力和交互逻辑在 `assets/scripts/GameModel.ts` 等脚本中修改。

## 游戏与资源

游戏包含可平移、缩放的 30×30 格棋盘，外围为城市背景。支持触屏拖放、双指缩放、卡包抽取、生产配方、账户、供应链、月末结算和商战。默认测试模式提供一个余额为 50 的账户；在设置中关闭后重新开始，使用普通开局。月末先扣散装现金，再扣账户余额。

左下角为顶部栏同款轮廓的彩色蜡笔卡车按钮，使用灰蓝货厢、暖橙车身和浅蓝玻璃：点击后选择主体，再点另一张卡或牌堆，系统按配方自动识别上下游并立即连接。选中的主体显示虚线跑马框；连接后，上方会提示“完成供应链上游组建”或“完成供应链下游组建”，牌堆上方不再放置图标。产出先以实心黑点沿供应链运送，到达后才在下游生成卡牌；运输进度随暂停和存档保留。点空白处取消选择，长按仍用于立体卡牌预览。右下角为粗蜡笔回收图标，沿用拖入出售和免费解雇；左下和右下按钮均不显示文字。研发项目、研发点及其数值加成已移除，供应链连接可直接使用；旧存档保留经营进度并忽略旧研发字段。

每个浏览器使用自己的独立存档，无需注册；进度定时保存到本机浏览器存储，并在操作完成、页面隐藏及退出时补存。其他玩家或其他浏览器的进度互不影响。同一设备、同一浏览器重新进入网址后，点击“继续创业”恢复棋盘、卡牌、账户和进行中的生产或战斗；不同设备或浏览器各自开局。存档不上传服务器，清除网站数据后会重置；同一浏览器配置内的多个标签页共用存档。数据更新沿用现有存档格式；新增卡牌使用新的唯一 id。

底部中间的蜡笔按钮切换继续／暂停。暂停时棋盘和卡牌褪淡 30%，UI 与卡包保持原色；音乐以 0.7 倍速度播放，时间、生产和运输停止，仍可拖放。底部三个图标较上一版再缩小 20%，保留原点击热区。竖屏提示栏约 59 像素高，分两行显示所点卡牌的属性和 flavor，两行中心间距约 21 像素，字号不变；没有属性时，flavor 纵向居中。慢速音乐由原曲派生，修改原曲后运行 `python3 tools/create-slow-music.py` 重新生成。

每个卡包都有一款主题毛线徽章：车库创业的“企业家精神”、起步发展的“创业元老”、供应链管理的“供应链专家”、产品升级的“产品匠心”、办公空间扩大的“团队之家”、商战来袭的“商战勇气”、融资壮大的“资本助力”、上市时刻的“敲钟时刻”、国际扩张的“全球视野”和巨头竞争的“巨头挑战者”。徽章以较低权重进入对应卡包，拖到员工卡上后消耗道具并贴在牌面，每枚增加 1 点产能，可叠加，随存档保存。原始透明插画位于 `data/art/cards/badge_*.png`，数值和抽取配置仍在 Excel 中。敌人仅由系统移动和触发遭遇，玩家的点击、长按、拖动、叠牌、出售与供应链连接均不作用于敌人。

长按卡牌打开可翻转的立体预览，资料区展示功能、说明、产出配方和来源卡包。配方图标可继续进入对应卡牌预览。图鉴展示已解锁卡面和未解锁卡背，支持稀有度、类型、名称排序。设置、标签和图鉴与详情页共用半透明黑色遮罩，深夜加班模式会保留创始人周围的柔边光圈。

`assets/` 是 Creator 资源，`data/` 是编辑用数据和素材，`tools/` 是构建工具。卡面按类型配色，标题栏与圆圈共用强调色，边框和标题分隔线保留粗蜡笔笔触。笔触按卡牌 id 固定，更新数字时保持一致。卡牌保留原插画和数字角标；创始人的外圈与侧面均为幻彩色，现金、账户和应收尾款使用金黄底色与流动高光。网页启动显示 FrankFromFuture 猫咪 Logo。

## 验证与发布

```sh
npm run typecheck
npm run test:data
npm run test:rules
npm run test:progress
# 预览服务器启动后：
node tests/online-rendering.cjs
```

`test:data` 在临时副本中修改 Excel，核对数据和图片一起更新、新卡牌资源生成、重复构建复用资源，以及无效引用停止构建。不会修改正式表格。

网页地址：https://www.iambrizo.com/startx/ 。本地构建不会自动发布，发布方式见 [部署说明](deploy/README.md)。
