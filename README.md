# StartX

商战互动卡牌冒险游戏。当前只保留 Cocos Creator 3.8.8 工程，位置为 [cocos/](cocos/)。

- 编辑卡牌数据：[cocos/data/startx_data.xlsx](cocos/data/startx_data.xlsx)
- 数据字段与插画位置：[数据说明](cocos/data/README.md)
- 构建、运行与验证：[Cocos 工程说明](cocos/README.md)
- 线上游戏：https://www.iambrizo.com/startx/

修改 Excel 后，在 `cocos/` 运行 `npm run build:web`，构建会自动更新数据和卡面。无需手动导出。
